# 电力负荷预测项目
# ⚡ 基于 XGBoost 的电力负荷预测

> 基于历史电力负荷数据构建的 **多变量单步电力负荷预测** 项目，采用 **XGBoost** 进行建模，实现从数据预处理到模型训练、预测及模型保存的完整机器学习流程。

## 📖 项目简介

本项目利用历史电力负荷及相关特征数据，构建 **XGBoost（Extreme Gradient Boosting）** 回归模型，对未来单时刻电力负荷进行预测。项目涵盖数据清洗、特征工程、模型训练、模型评估及预测等完整流程，可作为电力负荷预测、时间序列机器学习建模及 XGBoost 实践的参考项目。

## ✨ 项目特点

* 📊 基于历史电力负荷数据进行建模
* 🚀 XGBoost 回归模型实现高效预测
* 📈 支持多变量输入、单步预测
* 🔄 完整的数据预处理与训练流程
* 💾 支持模型保存与加载
* 📝 训练日志自动记录，便于实验管理
* 🛠️ 模块化代码结构，便于扩展与维护

## 📂 项目结构

```text
.
├── data/          # 数据集及预处理后的数据
├── log/           # 训练日志与运行日志
├── model/         # 保存训练好的 XGBoost 模型
├── src/           # 核心业务逻辑、模型训练与预测代码
├── utils/         # 自定义工具函数与公共模块
└── README.md
```

## 🚀 功能流程

1. 导入历史电力负荷数据
2. 数据预处理与特征构建
3. 训练 XGBoost 回归模型
4. 保存训练模型
5. 加载模型进行预测
6. 输出预测结果并评估模型性能
